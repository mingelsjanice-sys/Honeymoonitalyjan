# Honeymoon Atlas v3 — live API.SH

Deze versie gebruikt de actuele API.SH Booking.com endpoints:
- GET /booking/v1/search
- GET /booking/v1/hotel-rooms

## Render
Build command: npm install
Start command: npm start
Environment variable: APISH_KEY=<jouw API.SH key>

De API-key staat alleen server-side in Render.
